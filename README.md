# Dracu website

Statik tanıtım sitesi. Harici paket veya build adımı gerektirmez.

## GitHub Pages

1. Bu klasördeki dosyaların hepsini deponun kök dizinine yükle.
2. `index.html`, `style.css` ve `script.js` aynı dizinde kalmalı.
3. GitHub deposunda **Settings → Pages** bölümünden `main` dalı ve `/(root)` seç.

Arama kutusu şu an açıkça belirtilen geçici prototip olarak DuckDuckGo'ya yönlendirir; Dracu'nun bağımsız arama motoru henüz hazır değildir.
